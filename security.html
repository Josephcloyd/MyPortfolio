Security / v1.0

Security and integrity.

This portfolio uses practical controls rather than security theatre. Public content is separated from protected administration and contact data.

Admin protection

Portfolio management is designed for an allowlisted administrator account with multi-factor authentication and database-enforced access rules.

Content safety

Dynamic text is escaped and external links and media are restricted to approved URL schemes and origins.

Contact protection

Production contact requests are designed to use server-side bot verification, origin checks, and connection-based rate limits.

Reporting

To report a security concern, email Danojosephclyde@gmail.com. Please avoid including sensitive details in a public channel.
